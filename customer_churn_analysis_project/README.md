
# Customer Churn Analysis Project

## Objective
Analyze customer behavior and identify patterns behind subscription cancellations (churn).

The project evaluates:
- User activity
- Engagement levels
- Subscription types
- Customer behavior trends

It also provides retention suggestions to reduce churn.

---

## Files Included
- app.py → Main Python program
- customer_data.csv → Sample customer dataset
- requirements.txt → Required library

---

## Features
- Calculates churn rate
- Identifies low activity users
- Analyzes churn by subscription type
- Suggests customer retention improvements

---

## How to Run

### Step 1: Install Python
Download Python:
https://www.python.org/downloads/

### Step 2: Install Required Library

pip install -r requirements.txt

### Step 3: Run the Program

python app.py

---

## Output
The program displays:
- Total customers
- Churned customers
- Churn percentage
- Customer behavior analysis
- Retention suggestions
